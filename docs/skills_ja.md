# スキルのインポートと管理

[简体中文](./skills.md) | [English](./skills_en.md) | 日本語 | [한국어](./skills_ko.md) | [Русский](./skills_ru.md) | [Español](./skills_es.md) | [Português (Brasil)](./skills_pt.md)

AnyModelBot 0.1.24 から、週報作成、文書処理、資料整理などの作業手順を ZIP 形式のスキルとしてボットに追加できます。

## インポート

1. 対象ボットの設定を開き、「スキル → ZIP をインポート」を選びます。
2. ローカルの ZIP を選び、名前、説明、ファイル数を確認します。説明を展開すると全文を読めます。
3. 「スキルを追加」をクリックします。関連する作業でボットが必要に応じて読み込みます。

ZIP ごとにスキルは 1 つです。`SKILL.md` は ZIP のルートにも、外側のフォルダー内にも置けます。`scripts/`、`references/`、`assets/` などの付属ファイルも保持します。インポート時に GitHub へ接続したり、インストール用スクリプトを自動実行したりすることはありません。

`SKILL.md` には YAML のヘッダーと指示本文が必要です。

```markdown
---
name: weekly-report
description: ユーザーの作業メモから週報を作成する。
---

完了した作業、問題点、翌週の予定を整理し、指定された形式でまとめる。
```

名前は英小文字、数字、単独のハイフンで構成し、最大 64 文字です。ZIP は最大 20 MB、展開後は最大 64 MB・2000 項目、`SKILL.md` は最大 256 KB です。インポートできるスキルはボットごとに 100 個までです。複数の `SKILL.md` がある場合はスキルごとに ZIP を作成してください。

## 使用・置き換え・削除

- スキルは追加したボットだけに適用されます。同じボットはアプリとチャットチャンネルで共通のスキルを使います。
- 一覧から説明の表示、有効化、無効化、削除ができます。変更はボットが待機状態になってから反映されます。
- 同名のスキルを再インポートし、確認後に「スキルを置き換え」を選ぶと更新できます。有効・無効の状態は維持されます。
- 削除しても、ワークスペースに作成済みの成果物は残ります。
- `media`、`computer-use`、`amb-app` などの組み込みスキルやカタログ Bot 付属のスキルは上書きできません。

実行にはボットの既存の権限を使います。Python、追加ソフトウェア、アカウント接続などが必要なスキルでは、その環境を用意してください。他クライアント専用のツールに依存する場合は調整が必要です。形式に対応していても、付属ツールがすべてインストールされているとは限りません。

## 保存先

展開したパッケージはデータディレクトリ内の `skills/<ボット ID>/` に保存し、有効なものを実行用の `dsh/<ボット ID>/skills/` にコピーします。インポート先は使用中の AnyModelBot インスタンスだけです。サーバー運用の場合、ファイルはそのサーバーに保存されます。有効なスキルの名前と説明、使用時に読み込んだ本文や参考資料は、選択したモデルに送るコンテキストになります。[データとプライバシー](./privacy_ja.md)も参照してください。
