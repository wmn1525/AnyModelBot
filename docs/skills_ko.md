# 스킬 가져오기와 관리

[简体中文](./skills.md) | [English](./skills_en.md) | [日本語](./skills_ja.md) | 한국어 | [Русский](./skills_ru.md)

AnyModelBot 0.1.24부터 주간 보고서, 문서 처리, 자료 정리 등의 작업 방법을 ZIP 스킬 패키지로 봇에 추가할 수 있습니다.

## 가져오기

1. 대상 봇의 설정에서 「스킬 → ZIP 가져오기」를 선택합니다.
2. 로컬 ZIP을 선택하고 이름, 설명, 파일 수를 확인합니다. 설명을 펼치면 전체 지침을 볼 수 있습니다.
3. 「스킬 추가」를 누릅니다. 봇은 관련 작업에서 필요할 때 스킬을 불러옵니다.

ZIP마다 스킬 하나를 넣습니다. `SKILL.md`는 ZIP의 최상위나 바깥 폴더 안에 있어도 됩니다. `scripts/`, `references/`, `assets/` 등의 파일도 함께 유지됩니다. 가져올 때 GitHub에 접속하거나 설치 스크립트를 자동 실행하지 않습니다.

`SKILL.md`에는 YAML 헤더와 지침 본문이 필요합니다.

```markdown
---
name: weekly-report
description: 사용자의 업무 메모로 주간 보고서를 작성한다.
---

완료한 업무, 문제점, 다음 주 계획을 정리하고 사용자가 지정한 형식으로 작성한다.
```

이름은 영문 소문자, 숫자, 단일 하이픈으로 구성하며 최대 64자입니다. ZIP은 최대 20 MB, 압축 해제 후 최대 64 MB 및 2,000개 항목, `SKILL.md`는 최대 256 KB입니다. 봇당 최대 100개 스킬을 가져올 수 있습니다. `SKILL.md`가 여러 개라면 스킬별로 ZIP을 만들어 주세요.

## 사용, 교체, 삭제

- 스킬은 추가한 봇에만 적용됩니다. 같은 봇은 앱과 채팅 채널에서 같은 스킬을 사용합니다.
- 목록에서 설명 보기, 활성화, 비활성화, 삭제를 할 수 있습니다. 변경은 봇이 대기 상태가 된 후 적용됩니다.
- 같은 이름의 스킬을 다시 가져와 확인한 후 「스킬 교체」를 누르면 갱신됩니다. 기존 활성화 상태는 유지됩니다.
- 스킬을 삭제해도 작업 공간에 이미 생성된 결과물은 유지됩니다.
- `media`, `computer-use`, `amb-app` 등의 내장 스킬과 카탈로그 Bot에 포함된 스킬은 덮어쓸 수 없습니다.

스킬은 봇의 기존 권한으로 실행됩니다. Python, 추가 소프트웨어, 계정 연결이 필요한 스킬은 해당 환경을 갖춰야 합니다. 다른 클라이언트 전용 도구에 의존한다면 수정이 필요할 수 있습니다. 형식 호환이 모든 도구의 설치를 의미하지는 않습니다.

## 저장 위치

압축을 푼 패키지는 데이터 디렉터리의 `skills/<봇 ID>/`에 저장하고 활성화된 스킬을 실행용 `dsh/<봇 ID>/skills/`로 복사합니다. 가져오기는 현재 사용하는 AnyModelBot 인스턴스로만 전송됩니다. 서버에서 운영한다면 파일은 그 서버에 저장됩니다. 활성화된 스킬의 이름과 설명, 사용 시 읽은 본문이나 참고 자료는 선택한 모델에 보내는 문맥에 포함됩니다. [데이터 및 개인정보](./privacy_ko.md)를 참고하세요.
