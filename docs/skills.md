# 导入和管理技能

简体中文 | [English](./skills_en.md) | [日本語](./skills_ja.md) | [한국어](./skills_ko.md) | [Русский](./skills_ru.md) | [Español](./skills_es.md) | [Português (Brasil)](./skills_pt.md)

从 AnyModelBot 0.1.24 起，你可以把已有的工作流程作为 ZIP 技能包添加给机器人，例如写周报、处理文档或整理资料。

## 导入

1. 打开目标机器人的设置，找到「技能」，点击「导入 ZIP」。
2. 选择本地 ZIP，核对技能名称、说明和文件数量；可展开查看完整说明。
3. 点击「添加技能」。机器人在相关任务中会按需加载这个技能。

每个 ZIP 包含一个技能。`SKILL.md` 可以在 ZIP 根目录，也可以放在外层文件夹里。`scripts/`、`references/`、`assets/` 等配套文件会一起保留。导入不需要访问 GitHub，也不会自动执行包里的安装脚本。

`SKILL.md` 需要 YAML 开头和正文，例如：

```markdown
---
name: weekly-report
description: 根据用户提供的工作记录撰写周报。
---

先整理已完成事项、遇到的问题和下周计划，再按用户要求的格式输出。
```

名称使用小写英文字母、数字和单个连字符，最多 64 个字符。ZIP 最大 20 MB，解压后最多 64 MB、2000 个条目；`SKILL.md` 最大 256 KB，每个机器人最多导入 100 个技能。包含多个 `SKILL.md` 时，请把所需技能分别打包。

## 从技能库或 GitHub 安装

- 打开「应用与技能」的「技能」标签，可以按用途分类、按作者浏览技能库里的技能；机器人设置的技能区也有「浏览技能库」。点「复制安装指令」，把这句发给任意机器人。
- 也可以直接把技能的 GitHub 链接（仓库、`/tree/<分支>/<路径>` 目录或 `SKILL.md` 文件）发给机器人，说「装一下这个」。
- 机器人会读出技能的名称、说明、来源、许可证和文件数，出一张确认卡片；点「安装」才写入，只装到这个机器人上。聊天渠道里回复卡片上的编号确认，飞书卡片上有按钮。只有主人能安装。
- 装好的技能在列表里标着来源「GitHub · 仓库」，「查看」里有仓库、路径、分支、安装时的提交号和安装时间。

## 使用、替换和删除

- 技能只对添加它的机器人生效；同一机器人通过应用或聊天渠道工作时共用这些技能（「我的技能」见下文）。
- 在技能列表中查看说明、启用、停用或删除。正在工作的机器人会等空闲后应用变更。
- 重新导入同名技能，预览后点击「替换技能」即可更新。替换保留之前的启用或停用状态。
- 删除技能会移除技能文件，工作区中已经生成的文件会保留。
- `media`、`computer-use`、`amb-app` 等内置名称以及目录 Bot 自带技能不能被导入包覆盖。

技能运行时仍使用机器人的权限。需要 Python、其他软件或账号连接的技能，必须具备对应环境；依赖其他客户端专用工具的技能可能需要调整。技能格式兼容不代表所有配套工具都已安装。

## 在对话里使用

- 在对话输入框左边点「+」›「技能与应用」，可以看到这个机器人现在能用的技能和应用。点一项，会把「用{名称}帮我……」填进输入框，补完再发送；用不用由机器人自己判断。
- 设置里每个技能的名称旁标着「已生效」「当前任务结束后生效」或「加载中」，下面一行「试试这样说」，点一下就填进这个机器人对话的输入框。
- 机器人用上技能或应用时，回复上方的处理过程会写「正在使用技能 · {名称}」或「正在使用 {应用}」；回复结束后折成一行「已使用：…」，点开能看到完整过程。
- 问机器人「你有什么技能」「你有什么应用」，它会列出现在能用的项，各附一句可以照着说的话。
- `SKILL.md` 里写了 `disable-model-invocation: true` 的技能，机器人不会自己用，也不出现在「技能与应用」里；在消息里写 `/技能名` 才会用上。

## 把做成的事存成技能

和机器人把一件事做对之后，可以把做法存成「我的技能」，下次直接用，也能设成定时。

- 发起：在输入框的「+」菜单点「存成技能…」，或发 `/skill`，或直接说「存成技能」。只想存一部分时说「把步骤 3 存成技能」。机器人正在回复时，会等这一轮结束再整理。
- 机器人先显示「正在整理技能…」，然后出一张草稿卡：标题和文件名、什么时候用、步骤、你纠正过的地方（可以取消勾选）、用到的应用和技能、「试试这样说」。点「编辑」可以直接改技能文件，改完会重新检查。不点「保存」不写任何文件；卡片 30 分钟后过期。
- 密钥（API Key、令牌、密码、验证码、Cookie、身份证号）不会写进技能，编辑时加回去也存不了。手机号、邮箱、人名、群名和工作区以外的文件路径会标出来，默认「运行时再问」：存成占位，每次用之前先问你；选「保留」才把原文写进技能。
- 任务没做完也能存：草稿写明卡在哪一步，存下来标为「未验证」，用它成功做完一次后去掉标记。
- 标题相同、或机器人判断是同一件事时，卡片会说改了几处，可以「更新」或「另存为新技能」。更新会留下上一版，在「管理」里可以恢复。
- 「我的技能」全局一份、只存在本机，最多 100 个，和各机器人导入的技能分开算。默认只在保存它的机器人上打开，在其他机器人设置的技能列表里打开开关就能用。只有主人能存；微信群、飞书群里不能发起。
- 技能列表里，「我的技能」的行有「查看」和「管理」。「管理」里可以导出 ZIP（只含这个技能自己的文件，含保留的个人信息时先提醒）、恢复上一版、删除。导出的 ZIP 能在另一台电脑上作为本地 ZIP 技能导入。
- 保存成功后点「设成定时」，机器人问清时间，建一条「让它做件事」的规则，每次按技能的最新版本运行。要操作电脑、生图生视频或开后台任务的技能，以及未验证的技能，不能设成定时。技能被删除、在这个机器人上被关掉，或者更新、恢复上一版后多了要先回答的内容、多了定时运行做不了的步骤、变成未验证时，规则会暂停，出现在「定时」的「需要处理」里。
- 技能超过 10 个时，列表顶部有搜索框和「全部 / 我的技能 / GitHub / 本地 ZIP / 已关闭」筛选；处理过程里的技能名可以点开看详情。

## 数据存放

导入包解开后保存在数据目录的 `skills/<机器人 ID>/`，启用项在运行时复制到 `dsh/<机器人 ID>/skills/`。导入仅上传到你正在使用的 AnyModelBot 实例；如果实例部署在服务器上，文件会存到那台服务器。启用技能的名称和说明，以及使用时加载的正文或参考资料，会成为发给所选模型的上下文。详见[数据与隐私](./privacy.md)。

「我的技能」保存在数据目录的 `my-skills/`，在哪个机器人上打开，运行时就复制到那个机器人的 `dsh/<机器人 ID>/skills/`。
