# 导入和管理技能

简体中文 | [English](./skills_en.md) | [日本語](./skills_ja.md) | [한국어](./skills_ko.md) | [Русский](./skills_ru.md)

从 AnyModelBot 0.1.24 起，你可以把已有的工作流程作为 ZIP 技能包添加给机器人，例如写周报、处理文档或整理资料。

## 导入

1. 打开目标机器人的设置，找到「技能」，点击「导入 ZIP」。
2. 选择本地 ZIP，核对技能名称、说明和文件数量；可展开查看完整说明。
3. 点击「添加技能」。机器人在相关任务中会按需加载这个技能。

每个 ZIP 包含一个技能。`SKILL.md` 可以在 ZIP 根目录，也可以放在外层文件夹里。`scripts/`、`references/`、`assets/` 等配套文件会一起保留。导入不需要访问 GitHub，也不会自动执行包里的安装脚本。

`SKILL.md` 需要 YAML 开头和正文，例如：

```markdown
---
name: weekly-report
description: 根据用户提供的工作记录撰写周报。
---

先整理已完成事项、遇到的问题和下周计划，再按用户要求的格式输出。
```

名称使用小写英文字母、数字和单个连字符，最多 64 个字符。ZIP 最大 20 MB，解压后最多 64 MB、2000 个条目；`SKILL.md` 最大 256 KB，每个机器人最多导入 100 个技能。包含多个 `SKILL.md` 时，请把所需技能分别打包。

## 使用、替换和删除

- 技能只对添加它的机器人生效；同一机器人通过应用或聊天渠道工作时共用这些技能。
- 在技能列表中查看说明、启用、停用或删除。正在工作的机器人会等空闲后应用变更。
- 重新导入同名技能，预览后点击「替换技能」即可更新。替换保留之前的启用或停用状态。
- 删除技能会移除技能文件，工作区中已经生成的文件会保留。
- `media`、`computer-use`、`amb-app` 等内置名称以及目录 Bot 自带技能不能被导入包覆盖。

技能运行时仍使用机器人的权限。需要 Python、其他软件或账号连接的技能，必须具备对应环境；依赖其他客户端专用工具的技能可能需要调整。技能格式兼容不代表所有配套工具都已安装。

## 数据存放

导入包解开后保存在数据目录的 `skills/<机器人 ID>/`，启用项在运行时复制到 `dsh/<机器人 ID>/skills/`。导入仅上传到你正在使用的 AnyModelBot 实例；如果实例部署在服务器上，文件会存到那台服务器。启用技能的名称和说明，以及使用时加载的正文或参考资料，会成为发给所选模型的上下文。详见[数据与隐私](./privacy.md)。
