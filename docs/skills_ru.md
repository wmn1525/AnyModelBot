# Импорт навыков и управление ими

[简体中文](./skills.md) | [English](./skills_en.md) | [日本語](./skills_ja.md) | [한국어](./skills_ko.md) | Русский

Начиная с AnyModelBot 0.1.24, боту можно добавлять готовые рабочие инструкции в виде ZIP-пакетов: например, для еженедельных отчётов, обработки документов и сбора материалов.

## Импорт

1. Откройте настройки нужного бота и выберите «Навыки → Импорт ZIP».
2. Выберите локальный ZIP и проверьте имя, описание и число файлов. Разверните инструкции, чтобы прочитать их целиком.
3. Нажмите «Добавить навык». Бот сможет загружать его для подходящих задач.

Каждый ZIP содержит один навык. `SKILL.md` может находиться в корне ZIP или внутри внешней папки. Файлы из `scripts/`, `references/`, `assets/` и других папок сохраняются. Импорт не обращается к GitHub и не запускает установочные скрипты автоматически.

Для `SKILL.md` нужны заголовок YAML и текст инструкций:

```markdown
---
name: weekly-report
description: Составить еженедельный отчёт по рабочим заметкам пользователя.
---

Сгруппируй завершённые задачи, проблемы и планы на следующую неделю, затем используй формат пользователя.
```

Имя состоит из строчных английских букв, цифр и одиночных дефисов, не более 64 символов. Размер ZIP — до 20 МБ, после распаковки — до 64 МБ и 2000 записей. `SKILL.md` — до 256 КБ. Для каждого бота можно импортировать до 100 навыков. Если в ZIP несколько файлов `SKILL.md`, упакуйте навыки по отдельности.

## Использование, замена и удаление

- Навык действует только для бота, которому вы его добавили. Этот бот использует одни и те же навыки в приложении и чат-каналах.
- В списке можно просмотреть инструкции, включить, отключить или удалить навык. Изменения применяются, когда бот свободен.
- Импортируйте навык с тем же именем повторно и после просмотра нажмите «Заменить навык». Состояние включения сохраняется.
- Удаление навыка оставляет созданные ранее результаты в рабочей папке.
- Встроенные имена `media`, `computer-use`, `amb-app` и навыки из комплекта ботов каталога нельзя перезаписать импортом.

Навыки используют существующие разрешения бота. Если нужны Python, другие программы или подключение аккаунта, подготовьте соответствующее окружение. Навыки, зависящие от инструментов другого клиента, могут требовать изменений. Совместимость формата не означает, что все нужные инструменты установлены.

## Хранение

Распакованные пакеты хранятся в `skills/<ID бота>/` внутри каталога данных. Включённые навыки копируются в `dsh/<ID бота>/skills/` для выполнения. Импорт передаёт файлы только используемому экземпляру AnyModelBot; при серверном развёртывании они сохраняются на этом сервере. Имена и описания включённых навыков, а также прочитанные при работе инструкции и справочные материалы становятся контекстом для выбранной модели. См. [Данные и конфиденциальность](./privacy_ru.md).
