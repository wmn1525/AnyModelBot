# 変更履歴

[简体中文](./CHANGELOG.md) | [English](./CHANGELOG_en.md) | 日本語 | [한국어](./CHANGELOG_ko.md) | [Русский](./CHANGELOG_ru.md)

アプリを使っていて気付く変更をまとめています。以前のバージョンは [GitHub Releases](https://github.com/modelflare-ai/AnyModelBot/releases) をご覧ください。

## 0.1.31 - 2026-11-10

### 新機能と改善

- 上流の 819fc63（0.1.30）まで同期。OKINTO ログイン、ウォレット、グループ別モデル、API Key 接続、画像生成を維持しました。
- Windows インストール版と Linux AppImage は標準で更新をバックグラウンド取得します。インストールはユーザーが再起動を選んだ時のみ行い、実行中のタスクがあれば待ちます。現在の未署名 macOS 版は引き続き手動更新です。0.1.28 以前からは本版を一度手動インストールしてください。
- 「更新内容」ダイアログとバージョン情報の更新履歴を追加。バージョン確認、ダウンロード、更新説明は本リポジトリを参照します。
- 4 つの公式 Bot に作品一覧と内容を並べるワークスペースを導入。完全な会話表示に切り替えられ、共通入力欄でモデル選択、添付、スラッシュコマンドを利用できます。
- 初回モデル選択、エラー説明、見つける画面のカバー、最近の会話検索を改善。認証コードと画面レイアウトを修正しました。
- 上流のディレクトリ分割とルート再構成に OKINTO を適応。残高通貨、無制限枠、グループ API を保持し、上流専用の Bot クレジット特典は表示しません。

## 0.1.28 - 2026-11-08

### 改善と修正

- 上流の 184efc2 まで同期。企業調査、PPT マスター、映像スタジオ、米国株リサーチを同梱し、初回表示とインストール時の Bot ダウンロードが不要になりました。更新時も既存のプロジェクトとデータを保持します。
- Bot ごとの ZIP スキルのインポート、プレビュー、有効化・無効化、置換、削除を追加しました。
- ローカルのチャット履歴検索を追加。Bot、会話、チャネル、日付で絞り込み、元のメッセージに移動できます。
- カタログ Bot の表示領域とスクロールを修正し、メディアタスクの記録と復旧に対応しました。
- ドライバーのダウンロード再試行、Electron チェックサムのキャッシュ、Intel Mac の Apple サービス接続修正を反映。OKINTO ログイン、グループ別モデル、画像生成を維持しました。

## 0.1.25 - 2026-11-05

### 修正

- OKINTO の画像生成で、画像の受信完了前に一時トークンが取り消され、転送が中断される問題を修正しました。
- JSON、SSE ストリームと複数の画像レスポンス形式の解析を改善しました。中断や解析失敗を明確に表示し、自動で再生成しません。
- 処理過程、履歴、診断のモデル名で中国語のグループ名を読みやすく表示し、内部ルーティングの接頭辞を非表示にしました。
- 画面とメッセージの旧ブランド表記を OKINTO / okbot に統一しました。

## 0.1.22 - 2026-11-04

### 新機能

- **自分の公式 API キーを使用：** アカウントがなくても使えるようになりました。初回起動時に「自分の API キーを使う」を押すか、「設定 → モデル」で OpenAI、Anthropic、Google Gemini、xAI、DeepSeek、Kimi、GLM、Qwen、MiniMax、Mistral のキーを入力してください。モデルへのリクエストは提供元へ直接送られ、料金は提供元から請求され、キーはこの端末にのみ保存されます。画像と動画の生成は引き続き Modelflare 経由でのみ利用できます。
- **ウェブ検索に Keenable を追加：** 「設定 → ネットワークとアクセス」で選択し、キーを入力してください。

### 改善と修正

- 設定の「Modelflare」タブの名前を「モデル」に変更しました。未ログインのときは、ここから Modelflare にログインできます。
- 企業リサーチ、米国株リサーチ、PPT マスターが日本語、韓国語、ロシア語に対応しました。

### プライバシー

- 公式 API キーのみでログインしていない場合、アプリは Modelflare のアカウントデータや価格一覧を読み取りません。内蔵ゲートウェイは公開のモデルカタログを models.dev から読み取ります。この通信にキーや会話の内容は含まれません。

## 0.1.21 - 2026-11-03

### 新機能

- **チャネルの接続がより簡単に：** 設定の接続画面を作り直しました。アプリごとに接続方法を表示するので、手順に沿ってコードをスキャンするかトークンを入力するだけです。最初のメッセージを待って紐付けを完了する場合も、その旨を表示します。同じアプリにアカウントを追加することもできます。

### 改善と修正

- **Bot を削除するときの影響を明示：** 確認画面に、その Bot が担当していたチャネルに今後どの Bot が返信するかを表示します。最後の Bot の場合は、それらのメッセージに返信がなくなることも知らせます。
- **「見つける」の Bot の削除：** 同じ確認画面のチェックボックスでデータを残すか選べます。
- **すっきりした画面：** ウィンドウ背景の光彩をなくし、操作はニュートラルな色に統一しました。文字サイズに 0.5 ピクセル単位を使わなくなり、Windows で文字がより鮮明になります。
- **残高の通知：** 残高が少なくなると、サイドバーにはその旨だけを表示します。金額はアバターを選ぶと確認できます。
- **すりガラス効果はシステムに連動：** 個別の設定をなくし、システムの「透明度を下げる」設定に従います。
- Bot の作成中は、サイドバーにアバターと名前をリアルタイムで表示し、作成後に別の Bot の画面が一瞬表示されることもなくなりました。
- ドロップダウンメニューがページのスクロールに追従するようになり、「見つける」のレイアウトも調整しました。

## 0.1.20 - 2026-11-03

### 新機能

- **見つける：** サイドバーに「見つける」を追加しました。専用の画面を持つ既製の Bot を使えます。開いたときはサンプルを表示し、最初のメッセージを送ったときにインストールします。不要になったらいつでも削除できます。
- **企業リサーチ：** 会社名を伝えると、財務、ニュース、業界、事業の 4 方面を調べ、重要な事実に出典リンクを付けたレポートを作成します。Python があれば PDF に書き出せます。
- **米国株リサーチ：** SEC の決算書類と提出書類をもとに調査レポートを作成します。すべての数字をたどれます。
- **PPT マスター：** 文書やテーマから編集可能な PPTX を作成します。テンプレートの作成や既存の PPT の編集もできます。Python が必要です。
- **12 種類の専門家アバター：** アバターの選択肢に、法律、医療、金融、プログラミング、デザインなど 12 分野のキャラクターを追加しました。

### プライバシー

- アプリは起動時とその後 6 時間ごとに anymodel.bot から Bot の一覧を読み込み、Bot を開くか使うときにそのパッケージをダウンロードします。これらの通信はダウンロードのみで、あなたのデータはアップロードしません。一覧が不要な場合は、環境変数 `AMB_CATALOG=off` を設定してください。

## 0.1.19 - 2026-11-03

### 重要な変更

- **ログインが必須になりました：** API キーの貼り付けは廃止し、Modelflare アカウントでのログインに統一しました。更新後、以前入力したキーはこのデバイスから削除され、ログインを求める案内が表示されます。ログインすれば Bot と会話はそのまま使えます。
- **Docker やリモート環境でもログインできます：** 任意のデバイスのブラウザーでログインし、ログイン後のアドレスバーのリンクをアプリに貼り付けます。コマンドラインのセットアップでは `remote` と入力します。

### 新機能

- **推論の強さ：** 自動、低、中、高から選べます。高いほど深く考え、返信は遅くなります。自動ではモデルが判断し、調整に対応しないモデルには影響しません。
- **モデルテストの詳細表示：** トラブルシューティングで、内蔵ゲートウェイと直接接続それぞれの結果を、ステータスコード、所要時間、元のエラーとともに表示します。

### 改善と修正

- モデル一覧の API が応答しない場合は最長 30 秒で待機を終えるため、「モデルをテスト」が回り続けなくなりました。
- 公式サイトのパートナーページ、トップページ、ダウンロードページを更新しました。

## 0.1.17 - 2026-11-03

### 新機能

- **5言語に対応：** 簡体字中国語と英語に加え、日本語・韓国語・ロシア語に対応しました。アプリ画面、トレイ、システムメッセージ、認証時の案内、公式サイト、利用ドキュメントを翻訳しています。初回起動時、設定、コマンドパレットから言語を切り替えられます。
- **API ドメインの選択と応答時間の測定：** `modelflare.dev`、`origin.modelflare.dev`、`cf.modelflare.dev` を手動で選択し、アプリを実行している端末から応答時間を比較できます。測定では API キーを送信せず、モデルも呼び出しません。ドメインの自動切り替えは行いません。
- **新バージョンの通知：** サイドバーと「このアプリについて」に更新を表示します。ダウンロードページを開くほか、そのバージョンの通知を非表示にできます。
- **公式サイトにパートナー向けページを追加：** 提携の案内と申込フォームを用意しました。送信先 API が未設定の場合はメールでの連絡を案内し、送信していない申込を送信済みとは表示しません。

### 改善と修正

- 翻訳ファイルをモジュールごとに整理し、リリース前に翻訳漏れ、プレースホルダー、複数形、ドキュメントのリンクを検証します。ロシア語の複数形、金額・日付の表示、日韓の文字入力、モバイル画面の改行を改善しました。
- Feishu と Notion の認証エラーを現在の言語で表示します。ローカルプロキシへの接続が拒否された場合は、元のエラーを残したまま対処方法を案内します。
- 公式サイトの空の演出、ダウンロードページ、モバイル表示を調整し、各言語の共有画像、検索エンジン向け言語情報、404 ページを追加しました。

## 0.1.16 - 2026-11-02

### 新機能

- **グループチャット：** ボットが 2 体以上あれば、サイドバーの ＋ からグループを作り、複数のボットと会話できます。@ で指定したボットが答え、指定しなければ最後に回答したボットが続けます。ボット同士も @ で引き継げます。モデル、ワークスペース、記憶は各ボットが持ち、費用も個別に集計します。

### 変更

- **残高表示をすっきりと：** 左下にはアバター、名前、設定ボタンだけを表示します。アバターを押すと残高確認とチャージができます。残高が通知基準を下回った場合は、従来どおりサイドバーに通知します。

## 0.1.15 - 2026-11-02

### 新機能

- **全ボットでアカウントを共有：** 設定 › 接続でチャットや Notion のアカウントを一度追加すれば、全ボットから利用できます。サービスごとに複数のアカウントを追加し、別名を付けられます。
- **チャットからボットを切り替え：** `/bot` で一覧を表示し、`/bot name` を一度送ると切り替わります。その会話は新しいボットを使い続けるので、毎回指定する必要はありません。各ボットもほかのボットを把握しており、尋ねると答えられます。
- **Telegram、Slack、Discord：** トークンを貼り付けて接続できます。公開アドレスは不要で、画像とファイルを双方向に送れます。
- **Notion：** ワンクリック認証またはトークンで接続できます。ボットはページの検索・読み取り・作成・編集、データベースへの問い合わせができます。ページは削除できません。
- **Feishu メッセージの読み取り：** QR コードで許可した後、どのボットにも「2 つ目の Feishu を確認して」と頼めます。あなたの権限でチャットを読み、メッセージを検索します。読み取り専用です。
- **QR コードで Feishu を追加：** チャットアカウントを追加するとき、App ID と Secret の入力に代えて、スキャンでアプリを作成できます。

### 改善

- **Web 検索に DeepSeek キーが不要に：** 既定で無料検索を使い、Tavily、Exa、Bocha、Zhipu、独自の SearXNG にも切り替えられます。
- **キャラクターと役割を分離：** アバターは外見だけを決め、テンプレートを選んでもアバターは変わりません。

### 変更

- チャネルの設定を各ボットの情報パネルから設定 › 接続へ移しました。既存アカウントは再ログインなしで移行し、既定の応答ボットも引き継ぎます。
- 所有者と許可リストをアカウント単位にしました。そのアカウントで許可された人はどのボットとも話せます。ボットを削除してもアカウントには影響しません。
