# 변경 내역

[简体中文](./CHANGELOG.md) | [English](./CHANGELOG_en.md) | [日本語](./CHANGELOG_ja.md) | 한국어 | [Русский](./CHANGELOG_ru.md)

앱을 사용하면서 확인할 수 있는 변경 사항입니다. 이전 버전은 [GitHub 릴리스](https://github.com/modelflare-ai/AnyModelBot/releases)를 확인하세요.

## 0.1.31 - 2026-11-10

### 새 기능 및 개선

- 업스트림 819fc63(0.1.30)까지 동기화하고 OKINTO 로그인, 지갑, 그룹별 모델, API Key 직접 연결 및 이미지 생성을 유지했습니다.
- Windows 설치판과 Linux AppImage는 기본으로 업데이트를 백그라운드 다운로드합니다. 사용자가 재시작을 선택해야 설치되며 작업 중에는 기다립니다. 현재 서명되지 않은 macOS 빌드는 수동 업데이트를 유지합니다. 0.1.28 이하는 이번 버전을 먼저 수동 설치해야 합니다.
- 새 업데이트 안내와 정보 페이지의 변경 기록을 추가했습니다. 버전 확인, 다운로드 및 업데이트 설명은 이 저장소를 사용합니다.
- 공식 봇 4개에 작품 목록과 콘텐츠를 나란히 보여 주는 작업 공간을 추가했습니다. 전체 대화로 전환할 수 있으며 공통 입력창에서 모델, 첨부 및 슬래시 명령을 사용할 수 있습니다.
- 최초 모델 선택, 오류 안내, 둘러보기 표지 및 최근 대화 검색을 개선하고 인증 코드 처리와 화면 배치를 수정했습니다.
- 업스트림 디렉터리 및 라우트 재구성에 OKINTO를 적용했습니다. 잔액 통화, 무제한 할당량 및 그룹 API를 유지하며 업스트림 전용 봇 크레딧 행사는 표시하지 않습니다.

## 0.1.28 - 2026-11-08

### 개선 및 수정

- 업스트림 184efc2까지 동기화했습니다. 실사 도우미, PPT 마스터, 영상 스튜디오, 미국 주식 리서치를 내장하여 최초 실행과 설치 시 봇을 다운로드할 필요가 없으며 업데이트 시 기존 프로젝트와 데이터를 보존합니다.
- 봇별 ZIP 스킬 가져오기, 미리보기, 활성화·비활성화, 교체 및 삭제를 추가했습니다.
- 로컬 채팅 기록 검색을 추가했습니다. 봇, 대화, 채널, 날짜로 필터링하고 원본 메시지로 이동할 수 있습니다.
- 카탈로그 봇의 콘텐츠 영역과 스크롤을 수정하고 미디어 작업 기록 및 복구를 추가했습니다.
- 드라이버 다운로드 재시도, Electron 체크섬 캐시, Intel Mac의 Apple 서비스 연결 수정을 반영했습니다. OKINTO 로그인, 그룹별 모델, 이미지 생성을 유지했습니다.

## 0.1.25 - 2026-11-05

### 수정

- OKINTO 이미지 응답을 모두 받기 전에 임시 토큰을 취소하여 전송이 끊기던 문제를 수정했습니다.
- JSON, SSE 스트림과 여러 이미지 응답 형식의 파싱을 개선했습니다. 전송 중단과 파싱 오류를 명확히 알리며 자동으로 재생성하지 않습니다.
- 처리 과정, 기록과 진단의 모델 이름에서 중국어 그룹명을 읽을 수 있게 표시하고 내부 라우팅 접두사를 숨깁니다.
- 화면과 메시지의 이전 브랜드 표기를 OKINTO / okbot으로 통일했습니다.

## 0.1.22 - 2026-11-04

### 새로운 기능

- **내 공식 API 키 사용:** 이제 계정 없이도 사용할 수 있습니다. 처음 실행할 때 ‘내 API 키 사용’을 누르거나 설정 → 모델에서 OpenAI, Anthropic, Google Gemini, xAI, DeepSeek, Kimi, GLM, Qwen, MiniMax 또는 Mistral의 키를 입력하세요. 모델 요청은 제공업체로 바로 전송되고, 요금은 제공업체가 청구하며, 키는 이 기기에만 저장됩니다. 이미지와 동영상 생성은 여전히 Modelflare로만 사용할 수 있습니다.
- **웹 검색에 Keenable 추가:** 설정 → 네트워크 및 접근에서 선택하고 키를 입력하세요.

### 개선 및 수정

- 설정의 ‘Modelflare’ 탭 이름을 ‘모델’로 바꿨습니다. 로그인하지 않았다면 여기서 Modelflare에 로그인할 수 있습니다.
- 기업 리서치, 미국 주식 리서치, PPT 마스터가 일본어, 한국어, 러시아어를 지원합니다.

### 개인정보

- 공식 API 키만 쓰고 로그인하지 않으면 앱은 Modelflare의 계정 데이터와 가격 목록을 읽지 않습니다. 내장 게이트웨이는 공개 모델 목록을 models.dev에서 읽으며, 이 요청에는 키나 대화 내용이 포함되지 않습니다.

## 0.1.21 - 2026-11-03

### 새로운 기능

- **더 쉬워진 채널 연결:** 설정의 연결 화면을 새로 만들었습니다. 앱마다 연결 방법을 보여 주므로 안내에 따라 코드를 스캔하거나 토큰을 입력하면 됩니다. 첫 메시지를 기다려 연결을 마쳐야 할 때도 바로 알려 줍니다. 같은 앱에 계정을 더 추가할 수도 있습니다.

### 개선 및 수정

- **봇을 삭제할 때 영향을 명확히 안내:** 확인 창에 그 봇이 맡던 채널에 앞으로 어떤 봇이 답할지 표시합니다. 마지막 봇이면 해당 메시지에 답이 오지 않는다고 알려 줍니다.
- **둘러보기 봇 제거:** 같은 확인 창의 체크박스로 데이터를 남길지 고를 수 있습니다.
- **더 깔끔한 화면:** 창 배경의 빛 번짐을 없애고 동작은 중립색으로 통일했습니다. 글자 크기에 0.5픽셀 단위를 쓰지 않아 Windows에서 글자가 더 선명합니다.
- **잔액 알림:** 잔액이 적어지면 사이드바에는 그 사실만 표시합니다. 금액은 아바타를 선택하면 볼 수 있습니다.
- **반투명 효과는 시스템 설정을 따름:** 별도 설정을 없애고 시스템의 투명도 줄이기 설정을 따릅니다.
- 봇을 만드는 동안 사이드바에 아바타와 이름을 바로 보여 주며, 만든 뒤 다른 봇 화면이 잠깐 나타나지 않습니다.
- 드롭다운 메뉴가 페이지 스크롤을 따라가고, 둘러보기 화면의 배치도 다듬었습니다.

## 0.1.20 - 2026-11-03

### 새로운 기능

- **둘러보기:** 사이드바에 「둘러보기」가 추가되었습니다. 전용 화면을 갖춘 준비된 봇을 쓸 수 있습니다. 열면 먼저 예시를 보여 주고, 첫 메시지를 보낼 때 설치합니다. 필요 없으면 언제든 제거할 수 있습니다.

- **미국 주식 리서치:** SEC 재무 보고서와 공시 서류로 리서치 보고서를 작성합니다. 모든 숫자의 출처를 추적할 수 있습니다.
- **PPT 마스터:** 문서나 주제를 편집 가능한 PPTX로 만듭니다. 템플릿을 만들거나 기존 PPT를 수정할 수도 있습니다. Python이 필요합니다.
- **전문가 아바타 12종:** 아바타 선택 화면에 법률, 건강, 금융, 코딩, 디자인 등 12개 분야의 캐릭터가 추가되었습니다.

### 개인정보

- 앱은 시작할 때와 이후 6시간마다 anymodel.bot에서 봇 목록을 읽고, 봇을 열거나 사용할 때 해당 패키지를 내려받습니다. 이 요청은 내려받기만 하며 사용자의 데이터를 올리지 않습니다. 목록이 필요 없으면 환경 변수 `AMB_CATALOG=off`를 설정하세요.

## 0.1.19 - 2026-11-03

### 중요한 변경 사항

- **이제 로그인해야 사용할 수 있습니다:** API 키 붙여넣기는 더 이상 지원하지 않으며 Modelflare 계정 로그인으로 통일했습니다. 업데이트하면 이전에 입력한 키는 이 기기에서 삭제되고 로그인 안내가 표시됩니다. 로그인하면 봇과 대화를 그대로 사용할 수 있습니다.
- **Docker와 원격 배포에서도 로그인할 수 있습니다:** 아무 기기의 브라우저에서 로그인한 뒤 주소창의 링크를 앱에 붙여 넣으세요. 명령줄 설정에서는 `remote`를 입력합니다.

### 새로운 기능

- **추론 강도:** 자동, 낮음, 보통, 높음 중에서 선택할 수 있습니다. 높을수록 깊이 생각하고 답변은 느려집니다. 자동이면 모델이 결정하며, 조절을 지원하지 않는 모델에는 영향이 없습니다.
- **더 자세한 모델 테스트:** 문제 해결 화면에서 내장 게이트웨이와 직접 연결의 결과를 상태 코드, 소요 시간, 원본 오류와 함께 따로 보여 줍니다.

### 개선 및 수정

- 모델 목록 API가 응답하지 않으면 최대 30초만 기다리므로 "모델 테스트"가 계속 돌아가지 않습니다.
- 공식 웹사이트의 파트너 페이지, 홈 페이지, 다운로드 페이지를 업데이트했습니다.

## 0.1.18 - 2026-11-03

### 새로운 기능

- 5개 언어 지원, API 도메인 수동 선택과 응답 시간 측정, 업데이트 알림, 로컬 프록시 진단, 공식 사이트·다운로드·파트너 페이지 개선을 포함하는 정식 버전입니다. 자세한 기능은 아래 0.1.17 항목을 확인하세요.

### 수정

- Windows에서 CRLF 줄바꿈으로 체크아웃했을 때 문서 검사기가 로드맵 내용을 잘못 판정하는 문제를 수정했습니다. LF, CRLF, CR 회귀 테스트를 추가했습니다. 이 수정으로 앱의 실행 동작이 바뀌지는 않습니다.

## 0.1.17 - 2026-11-03

### 새로운 기능

- **5개 언어 지원:** 간체 중국어와 영어에 일본어, 한국어, 러시아어가 추가되었습니다. 앱 화면, 트레이, 시스템 메시지, 인증 안내, 공식 사이트와 사용 문서를 지원합니다. 처음 실행할 때나 설정, 명령 팔레트에서 언어를 바꿀 수 있습니다.
- **API 도메인 선택 및 응답 시간 측정:** `modelflare.dev`, `origin.modelflare.dev`, `cf.modelflare.dev` 중 하나를 직접 선택하고 앱이 실행되는 기기에서 응답 시간을 비교할 수 있습니다. 측정 시 API 키를 보내거나 모델을 호출하지 않으며 도메인을 자동으로 전환하지 않습니다.
- **새 버전 알림:** 사이드바와 앱 정보에서 업데이트를 확인하고 다운로드 페이지를 열거나 해당 버전의 알림을 숨길 수 있습니다.
- **공식 사이트 파트너 페이지:** 제휴 안내와 신청 양식을 추가했습니다. 제출 API가 설정되지 않은 경우 이메일 연락 방법을 안내하며, 실제로 보내지 않은 신청을 전송 완료로 표시하지 않습니다.

### 개선 및 수정

- 번역 파일을 모듈별로 정리하고 배포 전에 누락된 문구, 매개변수, 복수형, 문서 링크를 검사합니다. 러시아어 복수형, 금액·날짜 표시, 일본어·한국어 입력기, 모바일 줄바꿈을 개선했습니다.
- Feishu와 Notion 인증 오류가 현재 언어로 표시됩니다. 로컬 프록시가 연결을 거부하면 원래 오류를 보존하면서 해결 방법을 안내합니다.
- 공식 사이트의 하늘 효과, 다운로드 페이지와 모바일 화면을 다듬고 언어별 공유 이미지, 검색 엔진용 언어 정보와 404 페이지를 추가했습니다.

## 0.1.16 - 2026-11-02

### 새로운 기능

- **그룹 대화:** 봇이 두 개 이상이면 사이드바의 ＋를 눌러 그룹을 만들고 여러 봇과 동시에 대화할 수 있습니다. @로 지정한 봇이 답하고, 지정하지 않으면 마지막으로 답한 봇이 계속합니다. 봇도 다른 구성원을 @하여 작업을 넘길 수 있습니다. 각 봇의 모델, 작업 공간, 기억은 독립적이며 비용도 따로 추적합니다.

### 변경 사항

- **잔액 표시 간소화:** 왼쪽 아래에는 아바타, 이름, 설정 버튼만 표시됩니다. 아바타를 누르면 잔액을 확인하고 충전할 수 있습니다. 잔액이 알림 기준 아래로 내려가면 사이드바 알림은 계속 표시됩니다.

## 0.1.15 - 2026-11-02

### 새로운 기능

- **모든 봇이 계정 공유:** 설정 › 연결에서 채팅 및 Notion 계정을 한 번 추가하면 모든 봇이 사용할 수 있습니다. 서비스마다 여러 계정과 각각의 별칭을 지정할 수 있습니다.
- **대화에서 봇 변경:** 채팅 앱에서 `/bot`으로 목록을 확인하고 `/bot name`을 한 번 보내면 봇이 바뀝니다. 해당 대화는 선택한 봇을 유지하므로 매번 입력할 필요가 없습니다. 각 봇은 다른 봇에 대해서도 알고 있어 관련 질문에 답할 수 있습니다.
- **Telegram, Slack, Discord:** 토큰을 붙여 넣으면 연결됩니다. 공개 주소가 필요 없고 이미지와 파일을 양방향으로 주고받습니다.
- **Notion:** 한 번의 접근 허용 또는 토큰으로 연결합니다. 봇은 페이지 검색·읽기·생성·수정과 데이터베이스 조회가 가능합니다. 페이지 삭제는 할 수 없습니다.
- **Feishu 메시지 읽기:** QR 코드로 허용한 뒤 어떤 봇에게든 ‘두 번째 Feishu 확인해 줘’라고 요청하세요. 내 사용자 권한으로 채팅을 읽고 메시지를 검색하며 변경은 하지 않습니다.
- **QR 코드로 Feishu 추가:** Feishu 채팅 계정을 추가할 때 App ID와 Secret을 입력하는 대신 QR 코드를 스캔해 앱을 만들 수 있습니다.

### 개선 사항

- **DeepSeek 키 없이 웹 검색:** 기본 검색은 무료이며 Tavily, Exa, Bocha, Zhipu 또는 자체 SearXNG로 전환할 수 있습니다.
- **캐릭터와 역할 분리:** 아바타는 외형만 정하며 템플릿을 골라도 아바타는 바뀌지 않습니다.

### 변경 사항

- 채팅 채널 설정을 봇별 정보 패널에서 설정 › 연결로 옮겼습니다. 기존 계정은 다시 로그인할 필요 없이 자동 이전되며 기본 응답 봇도 유지됩니다.
- 소유자와 허용 목록은 이제 계정에 속합니다. 해당 계정에서 허용된 사람은 모든 봇과 대화할 수 있습니다. 봇을 삭제해도 계정에는 영향을 주지 않습니다.
