# 右侧预览面板：机器人交付的文件，在面板里看得清、看得全

**状态：** 已定稿
**适用版本：** 基于 v0.1.38
**日期：** 2026-11-15

## 阅读说明

线稿是需求的一部分。请逐张打开图片地址，结合相邻的文字一起理解；图文冲突时以文字为准。线稿里的规则、标注和文案都已在正文写成文字。文中「桌面版」指 macOS / Windows 应用，「网页版」指在浏览器里打开的界面；macOS 写「访达」的地方，Windows 对应「资源管理器」。

---

## 一、业务背景与要解决的问题

机器人做完事常交付文件，用户在右侧面板「预览」页签查看。现在：

- 面板默认 320 像素、最宽 440 像素且不超过窗口 34%，没有放大，看表格、网页、长文档很吃力。
- 顶部是「已打开的内容」下拉框和一排纯文字「用系统程序打开 / 在文件夹中显示 / 下载」，看不出开了几个文件；文字按钮像正文；桌面版的「下载」对本机文件多余。
- Markdown 不支持图片语法，网络图片和本地图片都只剩一个「!」，对话消息里也一样；CSV 是一整块纯文本；代码和 JSON 没有着色和行号；HTML 看不到源码；图片不能放大。
- 机器人改写了已打开的文件，预览不会自动更新。
- 文件过大或格式不支持时只有一行文字，没有可点的按钮；超过 2 MB 的文本一行都看不到。

**目标**：机器人交付的文件，在面板里一眼看清（表格是表格、代码有颜色、图文完整），需要时一步放大，文件变了自动是最新，出问题时知道原因和下一步。

## 二、产品逻辑

流程：点对话里的文件卡片、图片或链接 → 在「预览」新开或切到对应标签 → 面板自动变宽 → 按类型显示 → 需要细看时「放大」铺满窗口 → 机器人改写文件时自动刷新 → 关掉最后一个标签回到空状态。

- **面板结构**：「预览」页签下从上到下是面板顶栏（概览 / 预览 / 任务 / 记忆、放大、设置、关闭）→ 文件标签行 → 文件信息行 → 内容区。
- **适用范围**：机器人对话、群聊、历史消息搜索结果、专业机器人的工作台文件，凡用到右侧预览的地方一起生效。
- **支持类型**：Markdown、代码和纯文本、JSON、CSV / TSV、HTML、图片（含 SVG）、PDF、网址。

| 优先级 | 需求项 |
| :--- | :--- |
| P0 | R1 文件信息行；R2「⋯」菜单与另存为；R4 变宽与放大；R7 Markdown 图片；R8 对话消息里的图片；R11 CSV 表格 |
| P1 | R3 标签页；R5 各种状态；R6 自动刷新；R7 原文切换与渲染修正；R9 代码和纯文本；R10 JSON；R12 HTML；R13 图片 |
| P2 | R7 大纲；R14 PDF；R15 内容缩放；双击标签行放大 |

**本期不做**：视频和音频；跨对话的文件列表；Word、PPT、Excel 预览；在预览里编辑；标签拖动排序、拖出成独立窗口、独立预览窗口、系统全屏；重启后恢复标签；Markdown 数学公式、流程图、内嵌 HTML；预览内页面查找；自己做 PDF 工具栏；改变 HTML 的脚本和联网规则。

## 三、需求详情

### R1 文件信息行（P0）

- **去掉**：「已打开的内容」下拉框（由 R3 标签页取代）、手动刷新按钮（由 R6 自动刷新和「⋯」的「重新加载」取代）、「用系统程序打开 / 在文件夹中显示 / 下载」文字按钮行（收进 R2「⋯」）。「关闭当前预览」改为标签上的「×」。
- **位置**：标签行下方，高 44 像素，内容区滚动时不动。
- **左侧**：
  - 文件名：加粗；过长中间省略，保留扩展名。桌面版悬停显示完整路径，网页版悬停显示完整文件名。
  - 小文件夹图标：点击在访达中显示并选中文件。只在桌面版本机文件上显示；网址、网络图片没有。
  - 灰色辅助信息（「·」分隔）：Markdown 和 JSON 显示大小；代码显示「语言 · 行数」，纯文本只显示行数；CSV 显示「行数 · 列数 · 编码」；HTML 显示「网页 · 大小」；图片显示「像素尺寸 · 大小」；PDF 显示「页数 · 大小」，读不到页数只显示大小；网址显示「网页」。自动刷新后 1 分钟内追加「刚刚更新」；只显示了一部分时追加「前 2 MB」。
- **右侧**：类型专属控件 → 视图切换 →「⋯」。
  - 视图切换（分段控件）：Markdown「预览 / 原文」、HTML「预览 / 源码」、CSV「表格 / 原文」、JSON「格式化 / 原文」；其他类型没有。按文件类型记住上次选择，存在本机，重启后有效。
  - 宽度不够时，先把类型专属控件收进「⋯」（菜单最前面一组），再缩短文件名；视图切换和「⋯」始终显示。
- **样式**：可点文字操作用浅灰小胶囊；分段切换用现有分段控件；图标按钮用顶栏图标按钮样式；指针移上去变手形。
- **状态**：加载中时辅助信息先空、视图切换禁用；文件已删除时文件名变灰、文件夹图标置灰不可点、视图切换隐藏；失败、不支持、过大时视图切换隐藏。

### R2 「⋯」菜单与另存为（P0）

- 「⋯」在信息行最右；再点一次、点外面、按 Esc 关闭。
- **桌面版分四组**（各类型顺序一致，按类型增减）：①用系统程序打开、在访达中显示、另存为…；②复制内容、复制文件路径；③缩放（R15）；④重新加载、关闭标签页（右侧显示 ⌘W，Windows 显示 Ctrl+W）。
- **复制内容按类型**：Markdown「复制 Markdown」（原文）；代码文本「复制全部」；JSON「复制 JSON」（原文）；CSV「复制为 CSV」（当前排序和搜索后显示的行，带表头）；HTML「复制源码」；图片「复制图片」；网址「复制网址」；网络图片「复制图片地址」；PDF 没有这一项。只显示了一部分时复制显示的部分，菜单项后加「（已显示部分）」。
- **类型专属项**：HTML「在浏览器中打开」（系统默认浏览器打开文件，不额外提示）；网址和网络图片「在浏览器中打开 ↗」。
- **另存为…**：弹出系统保存对话框，默认原文件名，默认位置为上次另存的文件夹（第一次为「下载」文件夹）；同名由系统对话框询问替换；成功轻提示「已另存到「{文件夹名}」」，取消不提示，失败提示「没能保存，请换个位置再试」；保存的是磁盘上的原文件。
- **用系统程序打开**：遇到脚本或可执行文件（.js .py .sh .rb .php 等、Windows 可执行文件）不运行，改为在访达中显示，并轻提示「为了安全，脚本文件不会直接运行，已在访达中显示」。
- **在访达中显示**：与小文件夹图标同一动作。**复制**：成功「已复制」「已复制路径」，失败「复制失败，请重试」；路径为完整绝对路径。**重新加载**：重新读取，保持滚动位置。**关闭标签页**：同标签「×」；快捷键只在焦点位于预览面板时生效，否则保持系统行为。
- **网页版**：「在新标签页打开 ↗」「下载」｜复制内容｜缩放｜重新加载、关闭标签页；没有用系统程序打开、在访达中显示、复制文件路径、另存为；「下载」保存到浏览器下载位置并轻提示「已开始下载 {文件名}」；浏览器不允许写图片到剪贴板时不显示「复制图片」；不提供关闭标签快捷键。
- **状态**：文件已删除时只剩「复制文件路径」「关闭标签页」；加载中、失败、不支持、过大时不显示「复制内容」和「缩放」。

### R3 标签页（P1）

- **标签**：类型图标 + 文件名，过长末尾省略，最宽约 150 像素；当前标签浅灰底；只有当前和悬停的标签显示「×」。图标：Markdown 和纯文本为文档、代码和 JSON 为「< >」、CSV 为表格、HTML 和网址为地球、图片为图片、PDF 为 PDF、其他为普通文件。
- **排列**：新标签加在最右；放不下时左右滑动、右端渐隐；「+」固定在最右；切到看不见的标签时自动滚到可见。
- **打开**：点对话里的文件卡片、图片、Markdown 里的本地文件链接或图片、网址，在标签里打开并切过去；已在标签里的只切过去并重新读取一次。
- **上限**：最多 12 个；再打开时自动关掉最早打开且不是当前的那个，不提示。
- **关闭**：「×」、「⋯」的「关闭标签页」、焦点在预览面板时 ⌘W / Ctrl+W。关掉当前标签后切到右边的，没有就切到左边的；关掉最后一个回到空状态，面板恢复窄宽度。
- **右键**：桌面版「关闭」「关闭其他标签页」「复制文件路径」「在访达中显示」；网页版只有前两项；网址标签用「复制网址」代替「复制文件路径」，没有「在访达中显示」。
- **「+」菜单**：标题「本对话交付的文件」，列出当前对话机器人交付的全部文件，最新在上，可滚动；已打开的打勾、点击切过去；未打开的显示交付时间（今天「12:40」、昨天「昨天」、更早「11月13日」），点击新开标签；已不在的灰色、右侧「已不在」、不可点；底部固定「关闭其他标签页」「关闭全部」；没有交付文件时列表区显示「本对话还没有交付文件」。
- **范围**：每个机器人一套标签，群聊、历史消息搜索结果各一套；切到同一机器人的其他对话时标签保留，「+」列当前对话的文件。重启应用后标签清空，面板宽度、视图切换、缩放等偏好保留。
- **空状态**（没有标签时）：面板用窄宽度，顶栏不显示「放大」；第一行「点对话里的文件或网址，会在这里打开。」；下面列出本对话最近 3 个交付文件（最新在上、右侧交付时间，点击新开标签），超过 3 个时显示「查看全部 {n} 个」（点开同「+」菜单），没有交付文件时整块不显示；最下面「网站地址」输入框和「打开」，只接受 http / https 外部地址，无效时提示「请输入有效的网址（http 或 https）」。
- **网址标签**：地球图标 + 域名；信息行显示域名和「网页」，没有文件夹图标和视图切换，不自动刷新；内容区上方常驻一行说明（见文案）；「⋯」只有「在浏览器中打开 ↗」「复制网址」「重新加载」「关闭标签页」；变宽和放大同样有效。
- **状态**：文件被删除或移走时标签变灰、文件名加删除线、「×」常显，点开显示「找不到 {文件名}」，文件重新出现时自动恢复。

### R4 变宽与放大（P0）

- **变宽**：「预览」页签为当前且至少有一个标签时，面板用预览宽尺寸：默认约窗口 46%；拖动范围 400 像素到「窗口 64% 与 1200 像素中较小者」；对话区始终保留最小宽度。预览宽度单独记在本机，重启有效，和概览 / 任务 / 记忆的窄宽度互不影响。切回概览 / 任务 / 记忆或关掉最后一个标签时回到窄宽度。有工作台的专业机器人，预览与工作台共用一个宽度。宽度变化不做动画。窄窗口抽屉状态下，预览抽屉宽为「400 像素与窗口 64% 中较大者」，最多铺满窗口。

### R6 自动刷新（P1）

- **范围**：监听当前机器人所有已打开标签对应的文件；网址不监听；不在标签里的不监听。网页版同样生效。
- **当前标签**：文件 1 秒内不再变化后重新读取（连续写入合并）；同一文件最多每 2 秒刷新一次。保持位置：Markdown、代码、纯文本保持当前位置；JSON 保持折叠；CSV 保持排序、搜索和当前首行；图片保持缩放，像素尺寸变了回到「适应」；HTML、PDF 重新载入。底部轻提示「已更新到最新内容」约 2 秒，同一文件 30 秒内只提示一次；信息行「刚刚更新」1 分钟后消失。
- **正在选中文字时**：先不刷新，信息行出现「有新内容 · 刷新」小胶囊；点它或取消选中后刷新。
- **后台标签**：标记有更新，切过去时重新读取，不提示。
- **文件消失**：等 1 秒再确认，仍不在才显示「找不到」并标灰标签；同一路径重新出现时自动恢复。改名或移动按消失处理。
- **刷新失败**：保留上次内容，信息行显示「更新失败 · 重试」小胶囊。
- 「⋯」的「重新加载」随时可用。

### R7 Markdown（图片 P0；原文与渲染修正 P1；大纲 P2）

- **解析**：自动识别逗号、分号、制表符（.tsv 固定制表符）；支持带引号的字段，字段内可含分隔符和换行。编码自动识别 UTF-8、带 BOM 的 UTF-8、GBK；点信息行编码名弹出「文字编码」菜单：「自动识别（{结果}）」（打勾）、UTF-8、GBK，选后立即重新显示，在该标签关闭前记住。
- **表头**：「首行是表头」默认开；关掉后首行作为数据，表头为「列 1、列 2……」。
- **表格**：表头固定；左侧行号列固定，行号为原文件行号，排序后跟随；列宽按前 200 行估算，60–320 像素，可拖动，双击列边框按内容自动调整；过长单元格截断加省略号，悬停显示全文；非空单元格 90% 以上为数字（允许千分位逗号、负号、小数点、百分号）的列右对齐、按数值排序；行内列数不一致时少的补空，多出的列表头为「列 {n}」。
- **排序**：点表头升序 → 降序 → 恢复原顺序；文字列按文字排（中文按拼音）；当前排序列标色带箭头；只排显示的行。
- **搜索**：输入 0.2 秒后过滤，保留任一单元格包含关键词的行，不区分大小写，命中文字高亮；右侧显示「{命中} / {显示行数} 行」；无结果显示「没有找到「{关键词}」」；清空恢复。
- **上限**：文件不超过 10 MB 整份读取，表格最多显示前 50,000 行，超出时底部「只显示前 50,000 行（共 {总行数} 行），完整内容请用系统程序打开。」；超过 10 MB 只读前 10 MB，底部「文件超过 10 MB，只显示了前 {n} 行，完整内容请用系统程序打开。」；网页版提示中「用系统程序打开」换成「下载完整文件」。表格只渲染看得见的行。
- **状态**：只有表头时显示「只有表头，没有数据行」；解析失败（如引号不成对）自动切到原文并提示「没能按表格解析，已显示原文」；空文件按 R5。自动刷新保持排序、搜索和当前首行。

## 四、技术前提

1. 引入语法着色库，只打包常用约 30 种语言；同一个代码视图用于代码、Markdown 原文、HTML 源码、JSON、CSV 原文。
2. 表格只渲染看得见的行，支持 5 万行流畅滚动。
3. 读取文本时能判断 UTF-8 / 带 BOM 的 UTF-8 / GBK，并能按指定编码重新读取。
4. 能读取文件前一部分并截到完整的行，同时告诉界面总大小和可得时的总行数。
5. 按已打开的标签增减文件监听，并把变化推送到桌面版和网页版界面。
6. 桌面版由应用弹出系统保存对话框，并把保存到的文件夹告诉界面。
7. 「用系统程序打开」改为在文件夹中显示时，界面能拿到这个结果。
8. 对话页的面板能进入与「展开工作台」相同的铺满状态。
9. Markdown 本地图片走现有文件读取权限；网络图片请求不带来源信息。
10. 沙箱里的 HTML 页面链接能被拦截并改由系统浏览器或新标签打开；页面资源授权能自动续期。
11. ⌘W / Ctrl+W 只在焦点位于预览面板时改为关闭标签。
